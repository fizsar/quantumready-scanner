# Contributing

Thanks for your interest. QuantumReady is maintained by one person, so contributions are reviewed when time allows.

## Issues

Welcome, in English or Spanish:

- **A scan result that looks wrong**: use the "Scan result looks wrong" template. Include the report link, and ideally what another tool (testssl.sh, for example) says.
- **A bug in the code or the website**: use the "Bug" template.
- **Ideas**: use the "Idea" template. There is no public roadmap, so an idea may stay open for a long time.
- **Security**: never in an issue; see [SECURITY.md](SECURITY.md).

## Pull requests

**Code contributions are not accepted yet.** They will be once a Contributor License Agreement (CLA) is in place: the project is AGPL-3.0, and the CLA keeps the possibility of offering it under other terms later. Until then, please open an issue instead of a pull request.

When pull requests open, they will need:

- one change per pull request, with tests (`make test`, `make lint`);
- no secrets, real `.env` files or personal data in the diff;
- the CLA signed.
